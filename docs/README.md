# Документация YadroOS

Дерево `docs/` разбито по аудиториям, чтобы быстро находить нужные материалы.

## Обзор
- **User** — пользовательские руководства для CRM, коммуникаций, HR и финансов (`docs/user/`).
- **Technical** — архитектура, API, схема базы и гайд для разработчиков (`docs/technical/`).
- **Admin/Operations** — инструкции по запуску и обслуживанию (`docs/admin/`).

## Быстрая навигация
- Начало работы с продуктом: `docs/user/getting-started.md`.
- Архитектура и стэк: `docs/technical/architecture.md`.
- API и интеграции: `docs/technical/api-reference.md`.
- База данных: `docs/technical/database-schema.md`.
- Процесс разработки: `docs/technical/development-guide.md`.
- Запуск и поддержка в продакшене: `docs/admin/launch-checklist.md` и `docs/admin/maintenance-plan.md`.

При добавлении новых модулей или процессов обновляйте соответствующий раздел и добавляйте ссылку сюда для удобства поиска.
