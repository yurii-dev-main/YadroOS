# ВИСНОВКИ

У кваліфікаційній магістерській роботі вирішено актуальну науково-практичну задачу створення інтегрованої платформи для управління децентралізованою організацією, що забезпечує автоматизацію бізнес-процесів та ведення бухгалтерського обліку в єдиному інформаційному середовищі. На основі проведених досліджень та практичної реалізації отримано наступні результати:

Теоретичне узагальнення. Проведено глибокий аналіз еволюції організаційних структур, який підтвердив, що сучасні децентралізовані автономні організації (DAO) потребують специфічного інструментарію, відмінного від класичних ієрархічних ERP-систем. Виявлено, що ключовою проблемою існуючих ринкових рішень (Bitrix24, Odoo) є розрив між операційною діяльністю (CRM) та фінансовим обліком, що призводить до касових розривів та непрозорості управління. Запропоновано та обґрунтовано концепцію Real-time Accounting, згідно з якою бухгалтерські проводки генеруються системою автоматично на основі бізнес-подій, мінімізуючи людський фактор.

Системний аналіз та проєктування. Розроблено архітектуру системи на основі мікроядерного підходу та формалізовано моделі бізнес-процесів у нотації BPMN 2.0 (зокрема, «Обробка замовлення» та «Фінансовий процесинг»). Спроєктована інфологічна модель бази даних (ER-діаграма) забезпечує цілісність зберігання даних у третій нормальній формі, вирішуючи проблему дублювання інформації та забезпечуючи надійність зв'язків між сутностями клієнтів, угод та транзакцій.

Програмна реалізація. Створено клієнтську частину додатку (Frontend) з використанням бібліотеки React 18 та менеджера стану Zustand, що забезпечило високу чутливість інтерфейсу (SPA) та оптимізацію мережевого навантаження. Серверну частину реалізовано на платформі Node.js із застосуванням Prisma ORM, що дозволило використати єдину мову програмування TypeScript для всього технологічного стеку. Впроваджено алгоритми автоматичного розрахунку податків та генерації звіту P&L (Profit and Loss) через агрегацію даних безпосередньо на рівні СУБД PostgreSQL, що скоротило час підготовки фінансової звітності до мілісекунд.

Безпека та інфраструктура. Реалізовано комплексну систему захисту інформації, що включає протокол аутентифікації OAuth 2.0 / JWT із використанням пари токенів для захисту від XSS-атак. Впроваджено рольову модель доступу (RBAC), яка забезпечує баланс між автономією співробітників та централізованим контролем через механізм невідворотного аудиту подій (Audit Log). Процес розгортання автоматизовано через контейнеризацію Docker, що гарантує ідентичність середовищ розробки та експлуатації.

Практичне значення. Результатом роботи є повністю функціональний програмний продукт YadroOS, готовий до впровадження в малих та середніх IT-компаніях або розподілених командах. Використання розробленої платформи дозволяє скоротити адміністративні витрати на 20-30% за рахунок автоматизації рутинних операцій, підвищити фінансову дисципліну завдяки прозорості транзакцій та забезпечити прийняття управлінських рішень на основі даних реального часу.
