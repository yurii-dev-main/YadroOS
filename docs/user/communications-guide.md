**Navigate to**: Sidebar → Communications → Inbox

View emails, messages, and notifications from all channels in a single timeline.

## Email Management

### Connecting Mailboxes

1. Click Settings → Integrations → Email
2. Add new mailbox (IMAP/SMTP or OAuth for Google/Microsoft)
3. Authenticate and allow required permissions
4. Choose folders to sync (Inbox, Sent, Custom labels)
5. Save and test connection

### Composing & Replying

- Use the composer with templates, signatures, and attachments
- @mention teammates in the comment sidebar to collaborate before sending
- Schedule send or send later with timezone awareness

### Automations

- Create rules to auto-assign emails by subject, sender, or keywords
- Set auto-replies for after-hours or holidays
- Trigger CRM updates (create deal, log activity) when emails match conditions

## Internal Messaging

### Channels & Threads

- Join team channels for departments or projects
- Start direct messages with colleagues
- Use threads to keep conversations focused and organized

### Collaboration Features

- Share files and links with inline previews
- React with emojis and mark important messages as "Pinned"
- Start voice or video calls using integrated conferencing tools

### Presence & Availability

Set status (Available, Busy, Offline) and configure do-not-disturb schedules to manage interruptions.

## Integrations

### Telegram

1. Go to Integrations → Telegram
2. Connect your Telegram bot token
3. Map channels to CRM inbox folders
4. Enable auto-responses or forwarding rules

### Calendar

- Sync Google or Microsoft calendars for shared availability
- Create meetings directly from conversations
- Automatically log meeting notes back to the client record

### AI Assistant

Use AI suggestions to draft replies, summarize long threads, or translate messages into supported languages.

## Notifications & Preferences

## Best Practices

- Keep inbox zero by archiving or assigning conversations promptly
- Use tags and folders to organize communications by topic or client
- Document resolutions within the conversation thread for historical context
- Train AI responses with feedback to improve accuracy

## Troubleshooting

### Emails not syncing

- Verify IMAP/SMTP credentials or OAuth token validity
- Check firewall or security rules blocking mail server ports
- Review sync logs in Settings → Integrations → Email

### Missing Telegram messages

- Ensure the bot is an admin in the target channel
- Regenerate webhook secret if messages stop arriving
- Confirm integration is enabled and not paused

### Notification delays

- Confirm push notifications are allowed in browser/device settings
- Check if quiet hours or DND mode is active
- Monitor status page for service disruptions
