## Managing Clients

### Viewing Clients

**Navigate to**: Sidebar → CRM → Clients

You'll see all your clients in a list or grid view.

[Screenshot: Client list]

**Features**:
- **Search**: Type client name, email, or company
- **Filter**: By status, assigned person, tags
- **Sort**: By name, date added, revenue
- **Views**: Switch between list and cards

### Adding a New Client

**Method 1: Quick Add**
1. Click + button (bottom right)
2. Select "Add Client"
3. Fill required fields (name, email)
4. Click "Save"

**Method 2: Detailed Add**
1. Go to CRM → Clients
2. Click "New Client" button
3. Fill all information:
   - Basic info (name, email, phone)
   - Company details
   - Address
   - Tags
   - Assigned manager
4. Click "Create Client"

[Screenshot: Add client form]

### Editing Client Information

1. Open client card
2. Click "Edit" button
3. Update information
4. Click "Save changes"

**Quick Edit**:
- Click pencil icon next to any field
- Edit inline
- Press Enter to save

### Client Card

Click any client to see their detailed card.

**Tabs**:
- **Overview**: Basic information and stats
- **Deals**: All deals with this client
- **Activity**: History of interactions
- **Files**: Attached documents
- **Notes**: Internal notes

[Screenshot: Client card with tabs]

**Quick Actions** (top right):
- 📞 Call
- ✉️ Email
- 📅 Schedule meeting
- 📝 Add note
- 🗑️ Delete

### Importing Clients

Have clients in a spreadsheet? Import them!

1. Go to CRM → Clients
2. Click "Import" button
3. Download template CSV
4. Fill your data
5. Upload file
6. Map columns
7. Preview and confirm

[Screenshot: Import wizard]

**Tips**:
- Required fields: Name, Email
- Use consistent formatting
- Check for duplicates before import

## Sales Pipeline

### Understanding the Pipeline

**Stages** (drag deals between stages):

1. **Lead** - New potential clients
2. **Contact Made** - Initial contact established
3. **Qualification** - Assessing fit
4. **Proposal** - Sent proposal/quote
5. **Negotiation** - Discussing terms
6. **Closed Won** ✅ - Deal successful!
7. **Closed Lost** ❌ - Deal didn't work out

[Screenshot: Pipeline Kanban board]

### Creating a Deal

1. Go to CRM → Pipeline
2. Click "+ New Deal" or drag client to stage
3. Fill information:
   - Title (what are you selling?)
   - Client (select from list)
   - Value (amount)
   - Expected close date
   - Probability (%)
   - Assigned to (sales person)
4. Click "Create"

[Screenshot: New deal form]

### Moving Deals

**Drag and Drop**:
- Grab deal card
- Drag to new stage
- Drop

**Or manually**:
- Open deal
- Change stage dropdown
- Save

### Deal Card

Each deal shows:
- Client name
- Deal value ($)
- Probability (%)
- Days in current stage
- Assigned person (avatar)

Click to see full details.

[Screenshot: Deal card details]

### Pipeline Analytics

View metrics:
- **Total Pipeline Value**: Sum of all open deals
- **Win Rate**: % of deals closed won
- **Average Deal Size**: Mean deal value
- **Conversion Rate**: % moving to next stage

[Screenshot: Pipeline analytics]

## Activity Tracking

### Types of Activities

- 📞 **Call**: Phone conversations
- 🤝 **Meeting**: In-person or video meetings
- ✉️ **Email**: Email correspondence
- 📝 **Note**: Quick notes
- ✅ **Task**: To-do items

### Logging an Activity

**Quick Log**:
1. Open client or deal
2. Click "Log Activity"
3. Select type
4. Add details
5. Save

**Detailed Log**:
1. Go to client card → Activity tab
2. Click "+ New Activity"
3. Fill form:
   - Type
   - Date & time
   - Duration
   - Subject
   - Description
   - Attach files
4. Click "Save"

[Screenshot: Log activity form]

### Activity Timeline

See all interactions with a client in chronological order.

**Filter by**:
- Activity type
- Date range
- Team member

[Screenshot: Activity timeline]

### Setting Reminders

Never miss a follow-up!

1. Create activity
2. Set "Reminder" checkbox
3. Choose time (15 min before, 1 day before, etc.)
4. You'll get notification

## Reports & Analytics

### CRM Dashboard

**Navigate to**: CRM → Analytics

View key metrics:

**Sales Performance**:
- Revenue this month/quarter/year
- Deals won vs lost
- Average deal size
- Sales cycle length

**Team Performance**:
- Deals by salesperson
- Win rate by person
- Activity by person

**Client Insights**:
- New clients this month
- Client acquisition cost
- Client lifetime value
- Churn rate

[Screenshot: Analytics dashboard]

### Custom Reports

Create your own reports:

1. Go to Analytics
2. Click "Create Report"
3. Choose:
   - Metrics (what to measure)
   - Dimensions (how to group)
   - Filters (what to include)
   - Date range
4. Save and name your report

### Exporting Data

Export any list to Excel/CSV:

1. Go to list (clients, deals, etc.)
2. Apply filters if needed
3. Click "Export" button
4. Choose format (CSV or Excel)
5. Download file

## Tips & Best Practices

### 🎯 Keep Data Clean
- Update client info regularly
- Archive inactive clients
- Use tags consistently
- Avoid duplicate entries

### 📊 Use the Pipeline
- Move deals promptly
- Set realistic probabilities
- Update deal values
- Add notes on progress

### 📝 Log Everything
- Log all client interactions
- Set follow-up reminders
- Attach relevant files
- Keep notes detailed

### 🤝 Collaborate
- Assign deals clearly
- @mention teammates in notes
- Share important updates
- Use internal comments

### 📈 Review Analytics
- Check dashboard weekly
- Identify trends
- Spot bottlenecks
- Adjust strategy

## Troubleshooting

### Can't find a client?
- Check spelling
- Try partial name
- Use email search
- Check if archived

### Deal not moving?
- Check permissions
- Refresh page
- Try manual stage change

### Import failed?
- Check CSV format
- Verify required fields
- Look for special characters
- Try smaller batches
